Follow the fake.

Platforma dla analityków NASK. Prowadzi od jednej reklamy do operatora, który za nią stoi. Wskazuje przyszłe domeny kampanii, zanim pojawią się reklamy, i przygotowuje zgłoszenia dla całych kampanii zamiast pojedynczych reklam. Każde powiązanie ma dowody.

Otwórz Centrum dowodzenia Demo dla jury · 3 min Komponenty wyjaśnialności Identyfikacja wizualna

Wszystkie dane na makietach są fikcyjne: domeny, ID, osoby i liczby. Przełącznik „showApi” w Tweaks każdej makiety pokazuje endpointy API przy panelach.
